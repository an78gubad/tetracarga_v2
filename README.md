# Tetracarga

Describís una carga en castellano —"40 cajas de 60x40x30 de 12 kilos y 15 tambores de 200
litros"— y la ves consolidada dentro de un contenedor, en 3D.

El modelo de lenguaje solo interpreta la descripción. La disposición la calcula un algoritmo
determinístico, y un validador descarta cualquier disposición físicamente imposible antes de
mostrarla.
